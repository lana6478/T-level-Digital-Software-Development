# Sources and Further Reading

*Digital Software Development T Level → Sources and Further Reading*

This whole content library is a study-guide summary derived from the official specification for the T Level Technical Qualification in Digital Software Development (Level 3). It's meant to make the qualification's content easier to browse and revise from - but for anything assessment-critical (exact wording, mark allocations, command words, administrative deadlines), always check the primary source documents below.

## About this library

This is an **independent, unofficial study-guide repository**, part of the [UTC Leeds T Level Study Guides](https://lana6478.github.io/utc-leeds-t-levels/) project. It organises and paraphrases the official T Level specification into smaller, individually-named files and a searchable wiki-style site, to make the qualification's content easier to navigate - it is not a substitute for the specification itself and isn't produced or endorsed by Pearson or IfATE. It was built from **Version 1.1 (August 2026)** of the specification; if a later version is published, check the primary source above for anything that may have changed.

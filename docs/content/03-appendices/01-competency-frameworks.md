# Competency Frameworks and Command Words

*Digital Software Development T Level → Appendices → Competency Frameworks*

The specification signposts general English, maths and digital competencies against specific Occupational Specialism content, because that's where students get the most natural opportunity to develop them. These competencies are embedded in both the Core Component and the Occupational Specialism, using the short codes below (you'll see them referenced elsewhere in this guide, e.g. "E1, M6"). This page also lists the command word taxonomy used across Pearson's assessments for this qualification.

## Command word taxonomy

This table shows the command words used consistently across Pearson's assessments for this qualification, so students know exactly what kind of response each word expects. Not every paper uses every word - this list is for guidance.

| Command word | What it requires |
|---|---|
| Give / State / Name | Provide a response (e.g. a feature, characteristic, use, or justification for something). |
| Identify | Select the correct answer from the given context or stimulus. |
| Write | Write code using information from the given context or stimulus. |
| Describe | Provide responses linked in an appropriate logical order. |
| Explain | Identify a point and give a linked justification of that point. |
| Explain with additional justification | Identify a point, give a linked justification, then a third point that further justifies the first justification. |
| Discuss | Consider the factors that apply to a specific context, giving careful consideration to opposing aspects of an issue, situation or problem. No conclusion required. |
| Evaluate | Consider various aspects of a subject's qualities relative to its context (strengths/weaknesses, advantages/disadvantages), reaching an evidence-supported judgement, usually as a conclusion. |
| Draw | Produce a diagram (e.g. an algorithm, a process flow) using information from a given context or scenario. |
| Complete | Provide the missing information for a diagram so it's complete. |

## Key terms

- **Competency framework** - the shared set of English, maths and digital skills every T Level embeds and signposts against relevant content.
- **Command word** - the specific verb an exam question uses (e.g. "evaluate", "describe") that tells you exactly what kind of answer is expected.

# Core Scheme of Assessment

*Digital Software Development T Level → Core Component → Scheme of Assessment*

There are three assessments in the Core component: Core Examination Paper 1, Core Examination Paper 2, and the Employer Set Project. The mapping, timings and task order below reflect the current specimen assessment material - live assessments keep the same overall number and focus of tasks, but task order and detail can vary each series.

## Core examination structure

| | Paper 1 | Paper 2 |
|---|---|---|
| Format | Written examination | Written examination |
| Duration | 2 hours 15 minutes | 2 hours 15 minutes |
| Marks | 90 | 90 |
| Weighting | 30% of the core assessments | 30% of the core assessments |
| Content | 1. Problem solving 2. Introduction to programming 3. Emerging issues 4. Legislation and regulatory requirements | 5. Business context 6. Data 7. Digital environments 8. Security |

Both papers comprise two sections (A and B) that students answer in full, each getting more demanding as it progresses, assessed through a mix of short, medium and extended open-response items. Both are set and marked by Pearson, timetabled by Pearson, and must be run under examination conditions following JCQ's Instructions for Conducting Examinations (ICE).

## Employer Set Project

- Externally assessed project: up to **14 hours 30 minutes**, across multiple supervised sessions.
- Worth **40% of the core assessments** (100 marks).
- Draws synoptically on core content to respond to a vocational brief.
- Internet access and AI/preparation tools are not permitted during assessed sessions.
- Outcome: a portfolio of evidence submitted electronically (planning documentation, annotated digital portfolio, prototype digital product, testing evidence, evaluation), validated by an employer panel against the client's requirements and user experience.
- Set and marked by Pearson.

## Resources for delivery

The specification lists these as required for delivering the core component: diagramming/flowcharting software; Python 3 (3.10+) with an appropriate IDE; Python libraries including Pandas and Matplotlib (or comparable alternatives); spreadsheet software (for dataset handling, dashboards, project plans); plus general resources - a computer, internet access, audio/visual recording equipment, word processing/presentation/project management/basic image-editing/database software, web browsers, data sources, research resources, and a web server.

## Key terms

- **Assessment Objective (AO)** - a defined skill or ability an assessment measures, each carrying its own weighting.
- **JCQ ICE** - the Joint Council for Qualifications' Instructions for Conducting Examinations, the rules exams must be run under.

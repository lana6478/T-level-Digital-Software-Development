# Grading and Results

*Digital Software Development T Level → Overview → Grading and Results*

This page covers how the Technical Qualification is graded and awarded, the Uniform Mark Scale, how the overall T Level grade is calculated, and how results reach students and Providers.

## How the Technical Qualification is graded and awarded

### Calculation of the Technical Qualification grade

The two components are awarded across these grade ranges:

| Component | Available grade range |
|---|---|
| Core (including Core examinations and Employer Set Project) | A*-E and Unclassified |
| Occupational Specialism | Distinction, Merit, Pass and Unclassified |

The Core grade is calculated by aggregating points across each Core assessment to produce the A*-E grade. If a student's achievement in either component falls below Pearson's minimum standard, they receive an Unclassified (U) result for that component.

### Awarding the components

Grade boundaries are set for each component/sub-component (Core Examinations, Employer Set Project, Occupational Specialism) in every assessment series, through a process called **awarding**. This keeps standards consistent over time, so students get the same opportunity to achieve regardless of which assessment series they sit.

### Uniform Mark Scale (UMS)

For the Core component, students' raw marks are converted to a Uniform Mark Scale. This benchmarks outcomes between different assessment series, so a student who produces a C-grade-standard response in the Employer Set Project in one series gets the same uniform mark as a student performing at that same standard in a different series, regardless of raw marks.

The maximum uniform marks and grade boundaries per sub-component are fixed:

| Grade | Core Exam (max 240) | Core ESP (max 160) | Core Overall (max 400) |
|---|---|---|---|
| A* | 216-240 | 144-160 | 360-400 |
| A | 192-215 | 128-143 | 320-359 |
| B | 168-191 | 112-127 | 280-319 |
| C | 144-167 | 96-111 | 240-279 |
| D | 120-143 | 80-95 | 200-239 |
| E | 96-119 | 64-79 | 160-199 |
| U | 0-95 | 0-63 | 0-159 |

Where the Core component has two Core Exams (Paper 1 and Paper 2), the results are combined before converting to UMS.

### Calculation of the T Level grade

The Department for Education uses a T Level grade look-up table with minimum thresholds. Students must:

- complete both components,
- achieve at least a grade E in the Core, and
- achieve at least a Pass in the Occupational Specialism,

as well as successfully completing the other elements of the T Level, like the industry placement. Students who don't meet the minimum requirements are not certificated.

## Results transfer to Providers

### Technical Qualification result days

| Assessment series | Results day |
|---|---|
| Summer | August (Level 3 Results Day) |
| November | March (normally the third week, Level 3 Results Day) |

Pearson issues results directly to Providers and makes available:

- **Scorecards** - achievement in percentage terms against each Assessment Objective.
- **Results Plus** - an item-by-item breakdown so Providers can spot trends across and within cohorts, each labelled with its Assessment Objective.
- **Statement of Provisional Results** - a provisional component result slip, clearly watermarked as provisional.

Pearson doesn't require Providers to complete any forms or processes to claim the Technical Qualification result, since Pearson doesn't issue TQ certificates, T Level certificates, or T Level statements of achievement directly.

### T Level results reporting

The Technical Qualification forms part of the overall T Level. The Department for Education issues T Level results on Level 3 Results Day in August, and provides T Level certificates to students who successfully complete every element of the T Level.

## Key terms

- **Uniform Mark Scale (UMS)** - the standardised scale raw marks are converted to, so grades are comparable across different assessment series.
- **Awarding** - the process of setting grade boundaries each series to keep standards consistent.
- **Unclassified (U)** - the result given when a student's achievement falls below the minimum standard for a component.

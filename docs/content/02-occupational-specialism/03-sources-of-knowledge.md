# Sources of Knowledge

*Digital Software Development T Level → Occupational Specialism → Sources of Knowledge*

This is Content Area 3 of the Digital Software Development occupational specialism: discovering, evaluating and applying reliable sources of knowledge - both for research generally, and for gathering feedback to evaluate a software solution.

## 3.1 Evaluating the reliability of sources

Students use a range of sources to find information: search engines to locate reliable websites, wikis, blogs, academic papers, conversations with peers, forums, code comments, and code repositories.

To judge how reliable a source actually is, students evaluate:

- **Reputation** - who wrote it, and are they credible?
- **Bias** - was it written by a particular individual or organisation with an angle?
- **Evidence** - what evidence backs up the content?
- **Cross-referencing/triangulation** - does it agree with other independent sources?
- **Currency** - how up to date is it (when was it last updated)?

*(Signposted competencies: E1, E4-E6, M2, M4, M6-M8, D1, D3-D6.)*

## 3.2 Gathering data to evaluate a software solution

Students select and use a mix of qualitative and quantitative techniques to evaluate how well a software solution is working:

- Verbal feedback (formal and informal).
- Surveys and questionnaires.
- Performance and usage data.
- User observation, with observation records.
- Focus groups representing a cross-section of the target audience.
- Interviews, to gather individual users' thoughts on the solution.
- Peer mentoring.
- Formal line management and appraisal procedures.

*(E1, E4-E6, M2, M4, M6-M8, D1, D3-D6.)*

## Key terms

- **Triangulation** - cross-checking a claim against multiple independent sources before trusting it.
- **Qualitative data** - descriptive, non-numeric data (e.g. interview feedback, opinions).
- **Quantitative data** - numeric, measurable data (e.g. performance/usage statistics).
- **Focus group** - a small, representative group of target users consulted together for feedback.
